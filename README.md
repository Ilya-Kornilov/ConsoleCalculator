# ConsoleCalculator
Тестовое задание для "edme" на Java

Программа принимает на вход математическое выражение в виде строки, в которой должно быть два операнда и один оператор.
Оба операнда должны представлять собой целые числа от 1 до 10.
Оператором может являться лишь один из четырёх знаков, соответствующих математическим операциям:
  "+" (сложение), "-" (вычитание), "*" (умножение) или "/" (деление). *
Выражние должно вводиться следющим образом: "3 + 7". *
При соблюдении вышеперечисленных условий программа выводит полученное значение выражения в виде строки в консоль.
Например, в нашем случае "10". После чего программа завершается. *
  * (Ввод и вывод операторов, операнда и полученного значения происходят без кавычек)

Если вводятся:
  - менее или более двух операндов;
  - менее или более одного оператора;
  - числа иного диапазона (больше 10 или меньше 1);
  - дробные значения;
  - неверно указан операнд;
  - отсутствуют пробелы между операндами и оператором (только по одному);
  - имеются лишние пробелы;
  - вводится пустая строка,

программа выводит информацию об ошибке ("выбрасывает обработанное исключение") и завершается.
